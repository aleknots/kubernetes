Bem-vindo ao aleon.cloud. Este ambiente roda em um cluster Kubernetes multi-nó de produção implantado na Oracle Cloud Infrastructure (OCI), provisionado via Terraform, fortalecido com Ansible e gerenciado com Argo CD & Cloudflare Zero Trust.

Runtime de Containers: containerd 2.3
Kubernetes: v1.36.4 ARM64
Rede: Túnel Cloudflare (QUIC)

Ambientes do Cluster em Execução

Desenvolvimento (DEV)

Ambiente isolado de laboratório para testes de novas funcionalidades, overlays do Kustomize e iterações rápidas.

Abrir dev.aleon.cloud

Homologação (STG)

Ambiente de pré-produção com especificações idênticas às de produção para validação e testes de QA.

Abrir stg.aleon.cloud

Produção (PRD)

Ambiente de produção com limites estritos de recursos, estratégia de implantação blue/green e monitoramento.

Abrir prd.aleon.cloud

Argo CD (GitOps)

Motor declarativo de entrega contínua GitOps sincronizando o estado do GitHub diretamente no K8s.

Abrir argocd.aleon.cloud
